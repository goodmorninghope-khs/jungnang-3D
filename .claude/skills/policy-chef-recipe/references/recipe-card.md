# 레시피 카드 — 양식, 워크숍 진행안, 작성 예시

## 1. 빈 카드 (한 장)

```
┌──────────────────────────────────────────────┐
│ 우리 부서의 물음                               │
│ "                                          ?" │
│ 바꾸고 싶은 주민의 경험: (누가 / 언제 / 어디서)   │
├──────────────────────────────────────────────┤
│ ① MENU     주 메뉴: ____  보조: ____           │
│ ② 재료     Content  : 정보 ____ → 의미 ____     │
│   3C2A     Channel  : 주민을 만나는 접점 ____    │
│            Community: 함께 만들 사람 ____        │
│            Agenda   : 의제로 올릴 한마디 ____    │
│            Authority: 누가 말해야 믿나 ____      │
│ ③ 양념     (2~3개만) □FRAME □CONTEXT □RULE      │
│            □NUDGE □INSIGHT  → 어떻게: ____      │
│ ④ 도구     □DESIGN □DATA □AI  → 무엇을: ____    │
│ ⑤ 맛보기   R ____  O ____  I ____ (어떻게 알까)  │
├──────────────────────────────────────────────┤
│ 한 줄 레시피: "____를 ____로 바꿔 ____하게 한다" │
│ 실패하면 남길 징비 한 줄: ____                   │
└──────────────────────────────────────────────┘
```

## 2. 워크숍 진행안 (부서장 대상, 10–15분)

1. **(1분) 물음 세우기** — "우리 부서 일 가운데 주민이 가장 답답해하는 경험 하나는?" 한 문장으로 쓴다.
2. **(2분) 메뉴 고르기** — 다섯 메뉴 가운데 하나. 고르기 어려우면 "지금 필요한 게 이름(BRANDING)인가, 행동(CAMPAIGN)인가?"를 묻는다.
3. **(4분) 재료와 양념** — 3C2A 빈칸을 채우고 양념은 2~3개만 체크. 빈칸이 곧 약점이라고 알려 준다.
4. **(2분) 도구와 맛보기** — R·O·I마다 "무엇을 보면 알 수 있나"를 하나씩.
5. **(3분) 한 줄 레시피 발표** — 두세 부서만. 진행자는 마음·몸·눈 가운데 빠진 축을 짚어 준다.
6. **(1분) 마무리 물음** — "중랑에 산다는 것은 어떤 경험이어야 하는가?"

진행 팁: 정답을 고르는 시간이 아니다. 먼저 남의 레시피를 하나 보여 주고(아래 예시), 카드는 반쯤 채운 채로 가져가도 된다고 말한다.

## 3. 작성 예시

**예시 A — 올빼미버스 (서울시, 2013)**
- 물음: 막차가 끊긴 뒤 집에 가야 하는 사람들은 어떻게 귀가하는가?
- MENU: STORYTELLING (보조 CAMPAIGN)
- 재료: Content 심야버스 공급 → "새벽 노동자의 귀갓길" / Channel 정류장·버스 자체 / Community 대학생 SNS 제안, 승객 / Agenda 심야 노동 / Authority 서울시
- 양념: INSIGHT(통화 30억 건) + RULE(신청을 기다리지 않는 발견행정)
- 도구: DATA
- 맛보기: R 심야 이동 수요 / O 빅데이터 노선 설계 / I 시범기간 하루 평균 2,098명
- 한 줄: "통화 데이터를 노선으로 바꿔 새벽 귀갓길을 걷지 않게 한다."
- 징비: 심야버스는 달렸지만, 여전히 새벽에 걷는 사람들이 있었다.

**예시 B — 1트윗 = 1원 (2009)**
- 물음: 기부의 문턱을 얼마나 낮출 수 있을까?
- MENU: CAMPAIGN · 재료: Community(참여자가 금액과 기부처 결정) · 양념: NUDGE + RULE("1트윗 = 1원" 한 줄 규칙) · 도구: 트위터
- 맛보기: I 석 달 600명 넘게, 800여만 원(저서) · 아름다운재단 10주년 특별상
- 한 줄: "하루치 트윗을 기부로 바꿔 누구나 나눔의 문턱을 넘게 한다."

**예시 C — 배민 독립선언 (광주, 2024)**
- MENU: ISSUE FIGHTING · 재료: Agenda "독립선언", Community 사장님과 소비자 · 양념: FRAME(독립) + RULE(공공배달로 갈아타기)
- 맛보기: I 서명 1,547명(785+762), 공공배달 점유율 17.3% vs 전국 3.87%
- 징비: 수수료 구조는 남았다. "호소는 휘발된다. 구조는 남는다." → 다음 레시피는 규칙에서 시작한다.
