## 1. 큰 그림

```
CONNECTION DESIGN (새로운 연결 = 요리법 자체)
  ① 목적을 고른다      MENU         무엇을 하려는가
  ② 3C2A를 준비한다    INGREDIENT   무엇으로 만드는가
  ③ 5가지 맛을 더한다  SEASONING    어떻게 다르게 만드는가
  ④ 조리한다           TOOLS        칼·냄비·불
  ⑤ 간을 본다          TASTE · ROI  실제로 맛이 나는가
EXPERIENCE DESIGN (다른 경험 = 주민의 경험이 달라진다)
```
비전 문장은 「서울 디지털기본계획 2020」(2016)에서 김현성이 고른 **"새로운 연결, 다른 경험"**이다.

## 2. MENU 메뉴 5

| 메뉴 | 언제 고르나 | 대표 본인 사례 |
|---|---|---|
| **BRANDING** | 정체성과 이름을 세울 때 | DJ PI "대통령의 모든 것은 메시지다" · 청(聽)책 · 지산D소 |
| **ISSUE FIGHTING** | 쟁점에서 판을 옮겨야 할 때 | 배민 독립선언 · 네거티브 무대응(프레임에 말려들지 않기) · 제돌이 방류 |
| **CAMPAIGN** | 행동을 바꿔야 할 때 | 금연 「자학」 · 아름다운재단 1% · 하이파이브 |
| **STORYTELLING** | 숫자를 사람 이야기로 옮길 때 | 올빼미버스 · 서울씨 페르소나 · 떡볶이집 사장님 강사 |
| **NETWORKING** | 사람과 자원을 이어야 할 때 | One+100 · 트위터 민원 12만 건 · 청년 디지털닥터단 |

## 3. INGREDIENT 재료 3C2A

| 재료 | 바꾸는 방향 | 점검 질문 |
|---|---|---|
| **Content** | 정보 → 의미 | 이 메시지는 정보인가, 의미인가? 한 줄로 말할 수 있나? |
| **Channel** | 전달 → 접점 | 주민의 하루 동선 어디에서 만나는가? (P.O.E: Paid·Owned·Earned, "존재하는 모든 것은 매체다") |
| **Community** | 수용자 → 공동제작자 | 주민이 듣는 사람인가, 함께 만드는 사람인가? (2012 PR → PE) |
| **Agenda** | 의제 | 이 일을 사회의 의제로 올릴 말이 있는가? |
| **Authority** | 신뢰·권위 | 누가 말해야 믿는가? 공공이 먼저 해 봤는가? |

시민참여 사다리(2016~18 강의): ① 공개와 공유 → ② 민원과 제안 → ③ 토론과 제안 → ④ 시민참여 결정.

## 4. SEASONING 양념 5종과 세 축

| 축 | 양념 | 뜻 | 대표 사례 |
|---|---|---|---|
| **마음** (생각을 바꾼다) | **FRAME** 관점을 바꾸고 | 같은 사실을 다른 틀로 | 흡연 = 자학 · 잡상인 → 이동상인 · 지(地) → D |
| | **CONTEXT** 맥락을 읽고 | 때·곳·사람에 맞춘다 | 은평 분양 P.O.E 동선 매체 · 광주푸드클럽(11개 상품 → 축구 11명) |
| **몸** (행동을 바꾼다) | **RULE** 규칙을 바꾸고 | 판의 규칙 자체를 바꾼다 | 1트윗 = 1원 · 응답소 단일화 · 3·3·3 원칙 |
| | **NUDGE** 행동을 쉽게 | 문턱을 낮춘다 | "기부는 내 방 문턱 같이" · QR 스티커 한 장 · 가치삽시다 한 번 등록 |
| **눈** (보이지 않던 것을 본다) | **INSIGHT** 숨은 것을 발견하고 | 데이터와 현장에서 진짜 이유를 찾는다 | 통화 30억 건 → 올빼미버스 · 20대는 암보다 피부와 치아 · 떡갈비집 '소(상공인을) 버린' |

양념은 2~3개만. 원형은 2017.11 대구 강의의 '근의 공식'(Change the Rule / Insight / Frame / Nudge)이고, CONTEXT는 이후 디지털 펜타곤(Context)에서 더해졌다.

## 5. TOOLS 도구 — DESIGN × DATA × AI

- **DESIGN**: 1컷 1씬(금연), 서울씨 페르소나, 한 장 인포그래픽, 상세페이지 7:3
- **DATA**: 30억 건 통화(올빼미버스), 13억 키워드 백서, 열린데이터광장, 상권분석
- **AI**: 본인 사례 중 실행한 것은 아직 없다. AI-in-a-Box, 디지털 주치의, 중랑 "공공이 먼저 AI를 부린다"는 제안·진행 단계로 말한다.
- 맥락의 시대: "AI를 잘 쓰는 조직은 질문을 잘하는 조직이 아니라 맥락이 잘 쌓이고, 잘 찾아지고, 잘 연결되는 조직이다." 프롬프트는 가장 작은 한 겹이고, 바깥에는 지시·규칙 → 기억 → 자료·데이터 → 도구 → 주민의 삶이 있다. (참고: Schmid 2025.6.30, Anthropic 2025.9, Google Cloud)

## 6. TASTE 맛보기 R·O·I (2019.10 'Issue 판독 공식'이 원형)

| 항목 | 원문 정의 | 점검 질문 |
|---|---|---|
| **R**elevance | "당사자의 책임성과 연관성" | 주민 삶과 얼마나 맞닿는가? 우리가 할 일이 맞나? |
| **O**riginality | "과거의 사례나 상대적 확산성" | 처음 듣는 이야기인가? 퍼질 만한가? |
| **I**mpact | "여론화 가능성과 확대재생산의 정도" | 말이 되어 번지는가? 행동과 숫자로 남는가? |

ROI = R × O × I. 하나가 0이면 전체가 0이다. "간은 셰프가 아니라 손님이 본다."

## 7. 경험격차 → 경험디자인 → 경험복지

- **경험격차**: 민간은 정보비대칭이 풀리면서 소비자를 생산 과정에 적극 참여시켰다. 공급자 주도 시장에서 소비자 권력, 개인의 권력이 커진 결과다. 같은 시간 공공 서비스의 경험은 그만큼 따라가지 못했다. 그 차이가 경험격차다. (민간이 "스스로 혁신했다"고 쓰지 말 것. 본인 교정 사항)
- **경험디자인**: 레시피 5단계로 주민의 경험을 설계한다.
- **경험복지**: 누구나 격차 없이 좋은 경험을 누리는 것. "연결은 사치가 아니다. 복지이자, 생존이다."
- 마무리 물음: **"중랑에 산다는 것은 어떤 경험이어야 하는가?"**

## 8. 레시피는 어디서 왔나 (원형 연표 요약)

1998~ 마케팅 18질문('왜'를 묻는 습관) → 1999~2003 PI 3원·6전략 → 2005~07 정책광고 5원칙(금연) → 2009 입법 커뮤니케이션 5단계·PA → 2011~ 서울시 커뮤니케이션 3무 진단 → 2012 PR → PE → 2015 3·3·3 원칙, Park's way 14 → 2016~18 시민참여 4유형 → **2017.11 근의 공식(RULE·INSIGHT·FRAME·NUDGE)** → **2019.10 모래시계 모델 · R·O·I · P.O.E** → 2021 혁신 공식 → 2024.11 라면 순서론("스프를 먼저 넣은 라면과 면을 먼저 넣은 라면의 맛은 다르다") → 2026 레시피. '근의 공식'이 '레시피'로 이름을 바꾼 셈이다.

## 9. 왜 '정책셰프'인가

| 주방에서는 | 정책에서는 |
|---|---|
| 같은 재료도 양념과 불에 따라 맛이 달라진다 | 같은 예산, 같은 사업도 설계에 따라 주민의 체감이 달라진다 |
| 같은 맛도 먹는 사람과 자리에 따라 평가가 다르다 | 같은 정책도 누가, 언제, 어디서 겪느냐에 따라 평가가 갈린다 |
| 레시피가 있어야 누가 끓여도 그 맛이 난다 | 기준과 방법이 있어야 담당자가 바뀌어도 정책이 이어진다 |
| 간은 셰프가 아니라 손님이 본다 | 성과는 행정이 아니라 주민이 판정한다 |
